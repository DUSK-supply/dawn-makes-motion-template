# Packaging and retention rubric (stub)

Score each 0–5. Heuristic only; not a prediction of views.

| Criterion | 0 | 5 |
|---|---|---|
| Title clarity | Vague | Specific promise in < 60 chars |
| Curiosity gap | None | Clear open loop the video closes |
| Thumbnail readability | Cluttered | One subject, ≤ 3 words, readable at mobile size |
| Hook (first 15 s) | Intro/preamble | Payoff stated, stakes set |
| Pacing | Long static sections | A change every 5–10 s |
| Payoff | Promise unmet | Promise fully delivered |
